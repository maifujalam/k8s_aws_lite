1. Install helm chart for vault-secret-operator

Architecture:-
1. vault-operator: this SA in namespace vault-secret-operator is used to access vault with read-only.
   clluster role to read and list secrets, and bind tho this SA.

apiVersion: v1
kind: ServiceAccount
metadata:
  name: vault-secret-operator
  namespace: vault-secret-operator

2. In vault, create read-only policy for secretsdata.
 a. cd tmp
 b. write vault-operator-readonly.hcl

3. Create vault policy: vault policy write vault-operator-readonly vault-operator-readonly.hcl
4. Create vault role for vault-operator SA: vault write auth/kubernetes/role/vault-operator \
    bound_service_account_names=vault-secret-operator \
    bound_service_account_namespaces=vault-secret-system \
    policies=vault-operator-readonly \
