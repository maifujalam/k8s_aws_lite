Vault Secret Injector (Bank Vault)

Webpage: https://bank-vaults.dev/

Configure Readonly Access to vault-init container to read secrets from vault using vault-secrets-operator.
1. Login to vault using root token: vault login
2. Create a readonly policy to read key-value secrets from vault:
   vault policy write vault-operator-readonly - <<EOF
   path "secrets/*" {
     capabilities = ["read"]
   }
   EOF
